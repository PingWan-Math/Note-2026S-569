\section{Collection of Finiteness Properties}
\label{sec:collection-of-types}



\TypeF*

\CohomologicalDim*

\TypeFFP*

\TypeFH*

Some results:
\begin{itemize}
    \item  \(F\implies FH \implies FF \implies FP\).
    
    \item If there exists \(n-1\)-connected \(X\) with a free cocompact \(G\) action, then \(G\) has type \(F_n\) by turning \(\leftQ{X }{G }\) into a \(K(G,1)\). This proves \(F_n \implies FH_n\).
    \item Take the \(X\) you get, \(C_i(X)\) are finitely generated-free \(\Z G\)-modules, and this is exact because it's homologically \(n\)-connected. This proves \(FH_n \implies FF_n\).
    \item  \(F_n \implies FH_n \implies FF_n \iff FP_n\). (\cref{lem:FPn-implies-FFn} proves \(FP_n \implies FF_n\).) 
    
    \item There exists a group that has type \(FP_2\) but not type \(F_2\) (\cref{thm:FP2-not-F2}). 
        
    \item \(FH_1 \implies F_1\) because \(0\)th homology is about being connected.
    \item \(FF_1 \implies F_1\) See \cref{lem:FF1-implies-F1}.
\end{itemize}


Some open questions:
\begin{itemize}
    \item Does \(FP \implies FF\) (See \cref{q:FP-implies-FF})?

\end{itemize}
